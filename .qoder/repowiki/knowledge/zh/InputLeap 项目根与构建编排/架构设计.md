- 顶层 `CMakeLists.txt` 通过 `add_subdirectory(src)` 串联所有源码子目录，并在 UNIX/Windows/macOS 分支中分别启用 X11、libei、Carbon、MSWindows 等平台后端（由 `SYSAPI_*` / `WINAPI_*` 宏驱动）。
- 通过 `cmake/Version.cmake` 与 `cmake/Package.cmake` 注入版本号，再经 `configure_files()` 宏把 `dist/{rpm,wix,inno,macos}` 模板渲染到二进制目录，最终产出各平台的安装包。
- `resources/` 下的 `.desktop`、`.svg`、`.appdata.xml` 等静态资源由顶层 install 规则直接分发；`documentation/` 中的 man page 在 Linux 上被安装到 `share/man/man1`。
- 测试入口 `enable_testing()` 配合 `src/test` 子树，由 `clean_build.{sh,ps1}` 提供跨平台清理脚本，`towncrier.toml` 聚合 `doc/newsfragments` 生成 ChangeLog。
