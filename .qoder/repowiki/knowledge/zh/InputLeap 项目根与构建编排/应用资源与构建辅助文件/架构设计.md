本模块为纯资源目录，不包含可执行代码，按用途划分为：
- `icons/`：状态化 SVG 图标集（connected/disconnected/transferring 三态及 padlock），每个状态提供 mask 变体，供 UI 层根据连接状态切换。
- 桌面集成：`io.github.input_leap.input-leap.desktop` 与 `io.github.input_leap.input-leap.appdata.xml` 定义 Linux 桌面条目与应用元数据；`input-leap.ico`、`input-leap.png`、`banner.bmp`、`dialog.bmp` 为 Windows 安装器与窗口装饰位图。
- 许可证与说明：`License.rtf`、`License.tex`、`Readme.txt` 随安装包分发。
- 构建辅助：`doxygen.cfg.in` 是 CMake 模板，`${VERSION}` 占位符由构建系统替换后生成 `doc/doxygen` 下的 API 文档；`makeicon.sh` 依赖 ImageMagick 与 `png2icns`，从 `input-leap.png` 批量缩放并产出 Windows `.ico` 与 macOS `.icns` 多分辨率图标，输出到 `dist/macos/bundle/InputLeap.app/Contents/Resources`。
依赖方向单向向外：仅被上层打包/安装流程读取，不反向依赖源码。
